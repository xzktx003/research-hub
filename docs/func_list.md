# 功能清单

更新时间：2026-08-06

局域网访问地址：`http://10.30.0.22:8311`

## 仪表盘

- 展示当日论文、历史论文、来源与主题分布、流水线状态和系统能力健康。
- 支持按日期浏览、查看所有日期、全局搜索、定向发现和手动触发发现。
- 提供推荐阅读与分时长阅读路线。

## 论文库

- 按标题、作者、主题和日期检索论文。
- 展示 PDF 下载、解析、翻译和研读进度。
- 支持批量选择、批量处理、加入笔记本和打开阅读台。

## 阅读台

- 提供论文检索、原文信息、结构化解析、中文翻译、研读报告和技术卡片。
- PDF 使用服务端逐页渲染，支持翻页、缩放、适应宽度和显式下载。
- 研读报告支持复制与导出 Markdown。

## 主题中心

- 按主题聚合论文并展示主题摘要、数量和最新内容。
- 支持主题级日报笔记的查看与保存。

## 工作流

- 展示每日论文研读和专利交底书的顺序、并行分支、汇聚点与运行历史。
- 每日论文研读支持「立即发现」，启动发现、下载、解析和可选翻译；研读报告在阅读台按需生成。
- 专利交底书支持进入专利候选页，并明确查新与人工审批门禁。

## 任务中心

- 按任务类型、状态和关键词筛选当前已加载的最近 1000 条异步任务。
- 关键词覆盖论文标题、任务 ID、目标 ID、任务类型、结果和错误信息。
- 支持取消、单项重试、批量重试失败任务，并展示发现流水线进度。

## 关系视图

- 支持按论文标题或 ID 搜索关系、分页浏览和重建关系。
- 关系类型使用中文语义展示，同时在悬浮提示中保留原始类型。
- 支持关系卡片单项及批量折叠。

## 专利候选

- 从论文库形成候选组合，执行组合分析、现有技术查新和人工审批。
- 审批通过后生成版本化 Markdown 与 DOCX 交底书，并提供结构和证据自检。

## 笔记本

- 服务端持久化收藏论文，支持单篇移出、打开阅读台和卡片折叠。
- 支持带二次确认的批量清空；部分保存失败时保留失败项并提示结果。
- 汇总已有研读报告和技术卡片，并支持一键复制结构化摘要。

## 设置

- 配置 OpenAI 兼容或 Dify LLM、自动研读计划、全文翻译和主题展示条数。
- 展示系统托管服务、接口能力与适配器健康状态。
- 支持文字大小和浅色/夜间主题，保存后提供明确反馈。

## 验收约束

- 前端遵循严格 CSP，不使用内联样式或动态 `element.style` 修改。
- 新增交互由 `tests/unit/test_web_product_contracts.py` 提供产品契约回归测试。
- 后端测试使用隔离 SQLite 数据库，避免影响运行中的真实数据。
