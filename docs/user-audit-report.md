# 用户视角功能审计报告（2026-08-05 至 2026-08-06）

## 审计方法
以「依赖本仓库搜索和解析来阅读前沿技术的用户」身份，逐一使用每个功能，记录体验问题。

各页面的问题表保留首次审计时的发现，当前处理状态以文末「改进状态汇总」和执行记录为准。

## 第二批改进执行记录（2026-08-06）

- 工作流：每日论文研读卡片新增「立即发现」，按当前日期与回溯窗口启动发现、下载、解析和可选翻译，并明确研读报告按需生成；专利交底书卡片新增「进入专利候选」，并明确人工审批门禁。
- 任务中心：新增任务搜索，可按论文标题、任务 ID、目标 ID、任务类型和错误信息过滤。
- 笔记本：新增带二次确认的「清空笔记本」批量操作；逐项保存且保留失败项，避免部分失败时误报全部成功。
- 笔记本：研读摘要新增一键复制，输出带论文标题、总结、方法、创新点和工程价值的结构化文本。
- 关系视图：`complements/conflicts/similar/extends` 等类型统一显示中文语义，原始类型保留在悬浮提示中。
